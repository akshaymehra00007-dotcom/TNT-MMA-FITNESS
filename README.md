# TNT MMA Fitness Academy

A responsive, cinematic website for TNT MMA Fitness Academy in Bhopal.

## Run locally

This is a static website with no build step or dependencies. Serve this directory with any static HTTP server, for example:

```sh
python -m http.server 8000
```

Open `http://localhost:8000`. Deploy the repository root to any static hosting provider.

## Contents

- `index.html`: page, responsive styles, animation, and enquiry behavior.
- `logo.jpg`: original academy logo.
- `boxing-hero.mp4`: locally hosted stock boxing footage.

The WhatsApp form opens a prepared message to +91 97132 17866 using the visitor's name and training choice. The visitor sends the message in WhatsApp. No form data is stored by the website. Google Maps is embedded in the location section.

The hero video is muted and loops, with a still-image fallback. The motion button pauses video and animations; reduced-motion preferences are respected.
